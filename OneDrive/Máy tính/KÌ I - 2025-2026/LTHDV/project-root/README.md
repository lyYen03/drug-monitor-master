# Supplier-Product App

## Mô tả
Ứng dụng quản lý nhà cung cấp và sản phẩm. Có xác thực người dùng (session + cookie). Admin (người đã đăng nhập) mới có thể CRUD suppliers & products.

## Cài đặt
1. Copy project
2. `npm install`
3. Tạo `.env` theo mẫu:
4. `npm run dev` (hoặc `npm start`)
5. Truy cập `http://localhost:3000`
6. API docs: `http://localhost:3000/api-docs`

## Ghi chú
- Phần reset password/forgot chỉ demo (không gửi email).
- Đảm bảo MongoDB đang chạy.
